Skillproof

One skill that makes AI easier to use. About two minutes of your time upgrades your AI setup.

Visit Skillproof
Why I built it
Skills are like recipes: they tell your AI how to do a job well. But what if you don’t know which skills to use, or even what to improve? Skillproof finds the best ones for you and fits them seamlessly into your setup.
Stack
The skill is six Markdown files your AI reads and follows: it asks what you want, reads your setup without changing it, and adds skills from a checked list once you say yes. A daily Python job finds and safety-checks new skills, and a Node MCP server offers the same list to other AI tools. The site is plain HTML, CSS and JS on GitHub Pages.

Copy the prompt, paste it into your AI, say what’s off, approve the plan.

DATproof

An adoption accelerator for digital asset treasuries, built to teach Bitcoin treasury strategy and grow demand for it.

Visit DATproof
Why I built it
Digital asset treasuries will only become more common as crypto adoption increases. DATproof was built to defend the digital asset treasury model, prove its financial value and drive demand for it.
Stack
Python reads every filing where a tracked company reports a Bitcoin buy (SEC 8-Ks and Metaplanet’s notices) and adds it to the data. Each day a script rebuilds the page from that data and GitHub Actions publishes it to GitHub Pages.

Modelproof

Which AI model should you actually use? Model selection will only become more important. An independent, sourced tool to help you choose.

Visit Modelproof
Why I built it
New AI models arrive almost every week, and picking the ones that fit can leave decision makers stuck. Modelproof helps you decide, and lays the choice out so you can see it.
Stack
One data file holds each model’s prices, limits and the lab’s own words, each with its source and date. Node scripts in GitHub Actions collect it, and a checker opens every cited page to confirm each quote is really there. An MCP server shares the same facts with AI tools. The site is plain HTML, CSS and JS on GitHub Pages.

rls-guard

Audits your Supabase row-level security and hands you the fix SQL.

Visit rls-guard on npm
Why I built it
Row-level security decides who can read or change each row in a database. Getting it wrong is a common vulnerability in deployed apps. rls-guard finds the gaps and hands you the SQL that closes them.
Stack
An MCP server you run with npx. It tests your Supabase database from the outside, using only the public key, and writes the report as HTML and PDF.
